# Outcome Switch Monitor

Projet fait au HSIL Hackathon (emlyon, avril 2026).

Compare le critère principal enregistré d'un essai clinique (ClinicalTrials.gov) avec celui déposé avec les résultats, et classe les écarts.

```
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
demo/run.sh
```
